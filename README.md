# restaurant-table-booking-system
Information system for restaurant table reservation management
# Система бронирования столиков в ресторане

## О проекте

Информационная система предназначена для автоматизации процесса бронирования столиков в ресторане.

Система позволяет пользователям просматривать доступные столики, выбирать дату и время и создавать бронирование.

Администратор ресторана может просматривать и управлять бронированиями.

## Цель проекта

Создание удобной информационной системы для автоматизации бронирования столиков и уменьшения ручной работы персонала ресторана.

## Основные функции

- просмотр доступных столиков;
- выбор даты и времени;
- создание бронирования;
- отмена бронирования;
- просмотр своих бронирований;
- управление бронированиями администратором.

## Пользователи

### Клиент

- просматривает доступные столики;
- выбирает дату и время;
- создаёт бронирование;
- отменяет бронирование.

### Администратор

- просматривает бронирования;
- подтверждает или отменяет бронирования;
- управляет информацией о столиках.
