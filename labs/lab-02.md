# ЛЗ 2. Репозиторий и архитектурное решение

**Проект** — TABLE, система бронирования столиков в ресторане  
**Дисциплина** — IT жобаларды басқару  
**Группа** — АЖ-43

## Цель

Организовать хранение материалов и зафиксировать архитектурный выбор.

## Ход работы

Создали репозиторий и доску GitHub Project. Для фиксации решения подготовили ADR‑001. В приложении браузерный интерфейс взаимодействует с Flask, а данные хранятся в SQLite. Такая схема позволяет запускать систему локально без отдельного сервера базы данных.

## Результат

Репозиторий объединяет документацию, Issues фиксируют задачи, Project отражает их состояние. ADR сохраняет контекст и обоснование решения.
