# ЛЗ 12. Оценка ИИ-классификатора

**Проект** — TABLE, система бронирования столиков в ресторане  
**Дисциплина** — IT жобаларды басқару  
**Группа** — АЖ-43

## Цель

Проверить, как локальная модель определяет намерение гостя по тексту.

## Ход работы

Через Ollama запустили qwen2.5:3b и сравнили ответы с эталоном на 30 обращениях. Категории: создание, изменение и отмена брони, предзаказ, аккаунт. Использовали eval_30.csv и run_ollama_eval.py.

## Результат

Получено 22 правильных ответа из 30, точность 73,33%, средняя задержка 0,772 с. Все шесть обращений об аккаунте распознаны неверно. Результат допускает пилот с подтверждением оператором. Прямая плата внешнему API за локальный прогон составила 0, эксплуатационные расходы не измерялись.
