# Архитектура TABLE

Браузер → Flask страницы/API → SQLite. ШаблоныJinja2, JS/CSS. assistant_service.py отвечает FAQ и опциональному внешнему API; создание брони помощником использует ту же серверную функцию. db_integrity.py обеспечивает атомарные инварианты вБД. maintenance.py отвечает за копии, восстановление и напоминания. SMTP и публичная среда требуют отдельной настройки. [ADR](adr/README.md).
