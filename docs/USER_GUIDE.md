# Инструкция пользователя TABLE

## Посетитель

1. Откройте главную страницу `http://127.0.0.1:5000`.
2. Выберите дату, время и количество гостей, затем нажмите кнопку поиска доступных столиков.
3. Переключитесь между залом и террасой и выберите свободный стол.
4. При необходимости выберите блюда для предзаказа и укажите контактные данные.
5. Подтвердите бронирование. Номер брони сохраните для дальнейшего поиска.
6. Войдите в личный кабинет (`/login`) или зарегистрируйтесь (`/register`) для просмотра своих броней, истории и изменения профиля.
7. Доступную для отмены бронь можно отменить в личном кабинете. Отмена после начала посещения ограничена.
8. Для вопросов о столиках, бронировании и меню нажмите новую кнопку «Помощник» внизу страницы. Помощник не меняет данные брони.
9. Переключатели темы и языка (RU/KZ/EN) расположены в интерфейсе и сохраняют выбор браузера.

## Администратор

1. Откройте `/admin/login` и войдите с учётными данными администратора.
2. В `/admin` доступны дашборд, бронирования, столики, предзаказы, отчёты и журнал действий.
3. Изменяйте статусы бронирований и предзаказов с учётом текущего состояния.
4. Проверяйте журнал действий и сообщения об ошибках.
5. Для мониторинга сервера откройте `/health` или запустите `python monitor.py`.

## Ошибки

- «Неверный CSRF-токен» — обновите страницу и повторите действие; убедитесь, что сервер запущен с постоянным `SECRET_KEY`.
- «Стол занят» — выберите другое время или стол.
- Нет писем — проверьте SMTP-настройки; отсутствие SMTP не мешает локальному бронированию.
- Помощник не отвечает — проверьте сервер и `/health`, затем `logs/application.log`.
