# ADR 003 ИИ классификатор

Дата 08.11.2026. Статус: автономное внедрение отклонено, исследовательский пилот разрешён.

Контекст: Qwen2.5:3b дала 22/30 правильных классификаций, класс аккаунта 0/6. Требование пилота accuracy≥90% не выполнено.

Варианты: ручной выбор категории, правила, локальная LLM, внешний API. Ручная форма предсказуема, но добавляет шаг пользователю; правила дёшевы, но ограничены словарём; LLM понимает вариативный язык, но ошибается и требует оценки.

Решение: категория модели только рекомендация с подтверждением человеком. Запретить автономные изменения брони на основании категории. Выполнить новый eval с валидацией меток и независимой выборкой. Внешний API оценён отдельно по официальному тарифу Groq; токены Qwen не выдаются за точное потребление другой модели.

Последствия: сохраняется ручной контроль и его стоимость, снижается риск ошибочного действия. FAQ сайта и исследовательский классификатор остаются разными компонентами.
