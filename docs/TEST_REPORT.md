# Отчёт по автоматическим тестам

**Дата подготовки:** 29.10.2026.

## Набор тестов

| Тест | Ожидаемый результат |
|---|---|
| Главная и `/health` | HTTP 200, БД доступна |
| Регистрация и вход | HTTP 302, переход в личный кабинет |
| CSRF без токена | HTTP 403 |
| Создание брони | Успешный JSON |
| Повторная бронь на тот же стол и время | HTTP 409 |
| Отмена из личного кабинета | Статус `cancelled` |
| Защита admin API | Нет доступа без логина |
| Вход администратора, список столов | 16 столов |
| Меню и помощник | Доступный список блюд и текстовый ответ |

Тесты находятся в `tests/test_app.py` и используют **временную БД**, не затрагивая пользовательские записи.

## Фактическое выполнение

В среде подготовки архива отсутствовал Flask, а загрузка пакетов из сети была недоступна. Поэтому **исполнение интеграционных тестов не подтверждено**. Проверена компиляция исходников Python и структура архива. Не указывайте «9/9 пройдено», пока не выполните тесты локально.

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```
