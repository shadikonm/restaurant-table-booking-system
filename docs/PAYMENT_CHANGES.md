# Изменения в бронировании и демо-оплате

- Депозит 5 000 ₸ требуется **только**, если гостей больше 4 **или** добавлен хотя бы один пункт предзаказа.
- Для бронирований на 1–4 гостей без предзаказа раздел оплаты скрыт; прямой переход к /payment/<id> возвращает в кабинет.
- Способы оплаты: тестовая карта 4242 4242 4242 4242, 12/30, 123; демонстрационный QR; демонстрационный Apple Pay.
- **Настоящие карты вводить нельзя.** Платёжный шлюз не подключён. QR не является банковским QR. Реквизиты карты не отправляются на сервер и не сохраняются.
- После демонстрационного подтверждения показывается чек с номером брони, столиком, датой, временем, гостями, предзаказом и депозитом; можно распечатать или сохранить PDF.
- Административная форма входа получила новый CSS, соответствующий стилю сайта.
- В существующей базе ранее оплаченные бронирования не меняются.
