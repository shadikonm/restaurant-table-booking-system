# Текущая структура SQLite

Снимок схемы текущей версии. Пользовательские записи в комплект не включены.

## Состояния и ограничения

pending_payment, confirmed и arrived блокируют пересекающийся двухчасовой интервал; pending_payment освобождается после истечения payment_deadline. completed и cancelled не блокируют. Триггеры db_integrity.py проверяют пересечения, включая смену даты, и обязательную оплату при переходе в обслуживаемые состояния.

Столы 1–10 — зал; 11–16 — терраса. Вместимость: 1=2, 2=4, 3=4, 4=6, 5=4, 6=4, 7=6, 8=2, 9=4, 10=4, 11=2, 12=4, 13=4, 14=4, 15=2, 16=6.
