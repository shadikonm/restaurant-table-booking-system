# Нагрузочная проверка

Команда `python scripts/check_load.py` запускает локальный сервер с синтетической базой и200одновременных пользователей. Результаты: reports/load_200.json. Это короткий тест чтения и отдельная среда. До промышленной эксплуатации нужен целевой WSGI-сервер и отдельная проверка записей. Цельp95≤2с не объявляется достигнутой при превышении.
